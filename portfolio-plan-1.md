 # 4\. The "Lazy Developer" Principle

 The "lazy" personality should influence the UX.

 Not through poor UX.

 Through **simplicity**.

 Huzbi doesn't want to make visitors work to understand the site.

 Therefore:

 - Navigation should be obvious.
- Important information should be immediately accessible.
- Projects should be easy to browse.
- GitHub should be one click away.
- Contact should be obvious.
- Animations should be short.
- Pages shouldn't contain unnecessary sections.
- There shouldn't be endless scrolling for the sake of scrolling.

 The site can have hidden details for curious visitors, but the basic experience should be effortless.

 Think:

 > "I made this unnecessarily cool, but I also made sure you don't have to figure it out."
